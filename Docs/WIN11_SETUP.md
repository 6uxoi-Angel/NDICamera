# Настройка Windows 11 + OBS (DistroAV) для приёма NDI с iPhone

## 1. OBS + DistroAV

- OBS 30+ и плагин **DistroAV** (экс-NDI) — уже установлены.
- В OBS: «Источники» → «+» → **NDI Source** → выбрать имя источника (по умолчанию `iPhoneCamera`).
- Параметры входа (как в ТЗ):
  - **Bandwidth:** `Low` (HX / H.264)
  - **Sync:** `Network`
  - **Latency:** `Low`

## 2. Firewall (обязательно)

Разрешить входящие UDP-порты для NDI и mDNS:

```
netsh advfirewall firewall add rule name="NDI" dir=in action=allow protocol=UDP localport=5960-5963
netsh advfirewall firewall add rule name="NDI mDNS" dir=in action=allow protocol=UDP localport=5353
```

(Запусти в cmd от имени администратора. Для приватных сетей это обычно достаточно.)

## 3. Wi-Fi

- iPhone и ПК — в одной сети (одна подсеть, роутер без «изоляции клиентов»).
- Если mDNS не работает (не видит источник) → в приложении выбери **«Ручной IP»** и впиши IP ПК
  (узнать: `ipconfig` → IPv4-адрес).

## 4. USB (режим «Точка доступа»)

1. Установи **Apple Devices** (или iTunes) из Microsoft Store — даст драйвер **Remote NDIS**.
2. На iPhone: **Настройки → Сотовая связь → Точка доступа** → включи (можно поставить пароль).
3. Подключи iPhone кабелем к ПК → в Windows появится сетевой адаптер
   «Подключение по локальной сети * …» (Remote NDIS).
4. В приложении: поле **«Локальный IP»** оставь пустым (авто), транспорт — «Авто (mDNS)».
   Если не находит — напиши IP ПК в подсети точки доступа (обычно `172.20.10.*`).
5. Приём в OBS — как по Wi-Fi. Переключение Wi-Fi ↔ USB без перезапуска OBS:
   просто переключи транспорт/кабель и дождись «Авто-reconnect».

## 5. Смена имени источника

Приложение → Настройки → «Имя источника» → заполни → Start.
В OBS источник NDI обновится (пересоздай или переключи вход).

## 6. Диагностика

| Симптом | Что делать |
|---|---|
| OBS не видит источник по Wi-Fi | firewall (п.2), «изоляция клиентов» на роутере, ручной IP |
| Чёрный экран | в приложении формат H.264: AVCC → Annex-B |
| Картинка рвётся | снизь разрешение (720p) или битрейт (4–8 Мбит/с) |
| Звук не идёт | проверь «Передавать звук»; в OBS NDI Source → Audio |
| USB не виден как сеть | переустанови Apple Devices, другой кабель/порт |
