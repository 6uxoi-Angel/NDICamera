# Инструкция: бесплатная сборка NDICamera (.ipa) через GitHub Actions

Эта папка — **отдельный снапшот проекта** для сборки в облаке. Всё, что можно было автоматизировать, уже сделано за тебя. Остаётся 3 ручных шага, которые невозможно сделать за тебя (нужны **твои** аккаунты).

---

## Что УЖЕ сделано за тебя

- Готовый Xcode-проект (XcodeGen) — папка `src/`, `project.yml`.
- Workflow сборки: `.github/workflows/build.yml`:
  - **`build`** (всегда): собирает `.ipa` без подписи → артефакт `NDICamera-unsigned`.
  - **`signed-build`** (если добавлены секреты): подписывает бесплатной подписью Apple ID → артефакт `NDICamera-signed` — **именно его ставить на iPhone**.
- Скрипт `Scripts/Setup_github.bat` — делает всё ниже автоматически.
- Скрипт `Scripts/(обновление теперь через git pull)` — обновляет эту папку из основного проекта (если будешь править код).
- `NDISDK/README.txt` — куда положить NDI SDK.
- GitHub CLI (`gh`) уже установлен на этом ПК.

## Что нужно от тебя вручную (3 вещи, все бесплатные)

| # | Что | Где взять |
|---|-----|-----------|
| 1 | **NDI SDK** (iOS) | https://ndi.video → регистрация (бесплатно) → NDI SDK → iOS. Положить `libndi_ios.a` в `NDISDK\iOS\`, заголовки в `NDISDK\include\` |
| 2 | **GitHub аккаунт** | github.com — регистрация бесплатная (email + пароль) |
| 3 | **Apple ID + «пароль приложения» + Team ID** | appleid.apple.com → «Пароли для приложений» (создать) и Account → Membership (Team ID) |

> «Пароль приложения» — это НЕ обычный пароль Apple ID. Это отдельно сгенерированный код (~16 символов), который GitHub будет использовать для подписи.

## Быстрый путь (скрипт, рекомендуется)

1. **Положи NDI SDK** (п.1 выше) в `NDISDK\`.
2. Двойной клик по **`Scripts\Setup_github.bat`**.
3. Скрипт сам:
   - войдёт в GitHub (откроется браузер, подтверди вход);
   - создаст **публичный** репозиторий `NDICamera`;
   - запушит код;
   - спросит Apple ID / пароль приложения / Team ID → задаст их как секреты;
   - запустит сборку.
4. Иди на github.com → репозиторий `NDICamera` → вкладка **Actions** → дождись зелёной галочки (5–15 минут при первой сборке).
5. Внизу джобы — раздел **Artifacts** → скачай **`NDICamera-signed`** (файл `.ipa` внутри).
6. Перешли `.ipa` на iPhone (AirDrop / облако / почта).
7. На iPhone: **Настройки → Основные → Управление VPN и устройствами → Доверять разработчику** (появится после первой попытки установки).
8. Открой `.ipa` на iPhone (например, в «Файлах» или через AirDrop) → подтверди установку.

## Ручной путь (без скрипта, если не хочешь gh)

1. github.com → **New repository** → имя `NDICamera`, **Public**.
2. Залей содержимое этой папки (кнопка Upload files: перетащи `src/`, `project.yml`, `.github/`, `Docs/`, `NDISDK/`, `Scripts/`, `README.md`).
3. Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:
   - `APPLE_ID` = твой Apple ID
   - `APPLE_APP_SPECIFIC_PASSWORD` = пароль приложения
   - `TEAM_ID` = Team ID
4. Вкладка **Actions** → слева `Build NDI Camera (free macOS runner)` → **Run workflow** (кнопка справа).
5. Далее пункты 4–8 быстрого пути.

## Пересборка (бесплатная подпись живёт 7 ДНЕЙ)

Раз в неделю, пока бесплатная подпись:
1. github.com → Actions → **Run workflow** (одна кнопка).
2. Скачай новый `NDICamera-signed.ipa`.
3. Переустанови на iPhone (шаг 8 выше). Данные приложения сохраняются.

> Подписку на платный Apple Developer ($99/год) можно добавить когда угодно — тогда подпись станет годовой и пропадёт необходимость переустановки. Но это НЕ обязательно.

## Первая сборка: что проверять (код не компилировался локально!)

У меня нет Xcode, поэтому первая сборка — момент истины. Если будут ошибки компиляции, смотри в Actions вкладку логов. Вероятные места:

- **NDINative.mm** — имена функций/структур NDI SDK v6 (структуры могли переименоваться между версиями SDK). Сверь с `Processing.NDI.Lib.h` из твоего SDK.
- Если SDK требует **лицензию** — раскомментируй вызов `NDIlib_set_license` в `NDINative.mm` (сейчас он закомментирован) и положи `License.lic` рядом.
- Чёрный экран в OBS → в настройках приложения переключи «Формат H.264»: AVCC ↔ Annex-B.
- `signed-build` — если секреты заданы, но джоба серая/пропущена — проверь имена секретов (регистр букв важен).

## Troubleshooting

| Проблема | Решение |
|---|---|
| Сборка падает: `NDI SDK missing` | не положил `libndi_ios.a` в `NDISDK\iOS\` |
| `signed-build` не запускается | нет секретов или опечатка в имени (`APPLE_ID` и т.д.) |
| `fastlane cert` ошибка «not authorized» | пароль приложения создан неправильно / двухфакторка Apple |
| Установка: «Не удалось установить» | не доверял разработчика (шаг 7); или истекли 7 дней — пересобери |
| Приложение закрывается сразу | истекла подпись или несовместимость SDK/лицензии NDI |
| Actions не работают на аккаунте | github.com → Settings → Actions → разрешить |

## Как обновить код в этой папке

Правь код в основном проекте `C:\Users\God\Projects\NDICamera`, затем запусти `Scripts\(обновление теперь через git pull)` — он скопирует изменения сюда и запушит на GitHub. Сборка перезапустится сама (по push в main).

## Структура

```
NDICamera-gha\
  project.yml                  # XcodeGen манифест
  src\                         # весь исходный код
  NDISDK\                      # ← сюда SDK (см. README.txt)
  Docs\WIN11_SETUP.md          # настройка OBS/DistroAV/firewall/USB
  Scripts\
    (обновление теперь через git pull)   # обновление из основного проекта
    Setup_github.bat        # главный скрипт: GitHub + секреты + сборка
  .github\workflows\build.yml  # бесплатная сборка
  README.md                    # описание проекта
```
